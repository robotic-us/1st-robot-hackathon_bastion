# Motion Graph GUI

PhORCE 모션 슬롯 1~30을 11단 수렴형 그래프로 보여주는 Tkinter 프로그램입니다.

## 그래프 구성

각 단에는 노드가 하나 있고, 다음 단으로 가는 선택지만 왼쪽·직진·오른쪽 3개입니다.
세 선택은 모두 같은 절대각도에서 시작해 같은 절대각도로 끝나므로 다음 노드에서
다시 합쳐집니다.

```text
1단 ○
    ↑ ↖ ↗  슬롯 1·2·3      0→360° (직진·좌회전·우회전)
2단 ○
    ↖ ↑ ↗  슬롯 4·5·6    360→720°
3단 ○
    ...
...
11단 ○      슬롯 28·29·30 실행 후 도착
```

- 11개 노드, 10개 이동 구간, 총 30개 간선
- 첫 구간은 `1=직진`, `2=좌회전`, `3=우회전`
- 두 번째 구간부터는 기존 순서인 `3n+1=왼쪽`, `3n+2=직진`, `3n+3=오른쪽`
- Motion 2/3은 차동 회전으로 좌우 휠의 종점 절대각도가 서로 다르므로, 완료 후
  다음 tree 구간은 자동으로 잠깁니다. 물리적으로 0° 시작 상태를 다시 만든 뒤 GUI를
  재시작해야 합니다.
- `phorce list --json`에 없는 모션은 회색 비활성화
- 현재 단의 다음 3개 간선만 클릭 가능
- 모션 성공 뒤에만 다음 단으로 진행

슬롯 31은 그래프에 포함되지 않는 `MD0` 단독 0→360° 테스트 모션입니다.
화면 상단의 `31 · MD0 단독 테스트` 버튼으로 언제든 별도 실행할 수 있고,
완료해도 현재 그래프 단계는 바뀌지 않습니다. PCM 카탈로그에 31번이 없으면 버튼은
자동으로 비활성화됩니다.

Action이 일시적인 Error 17을 먼저 반환해도 프로그램은 모션을 재전송하지 않습니다.
PCM 상태를 읽기만 하며 같은 모션이 `COMPLETED`, `physical_idle`, `last_err=0`에
도달했을 때만 성공으로 처리합니다.

## 실행

PCM과 Jetson 런타임을 먼저 연결한 뒤 실행합니다.

```bash
cd /home/phorce/bastion_ws/motion_tree_gui
python3 motion_tree_gui.py --domain-id 21
```

이미 첫 모션을 완료해 바퀴가 360° 종점에 있다면 2단에서 시작합니다.

```bash
python3 motion_tree_gui.py --domain-id 21 --start-node 1
```

`--start-node`는 표시만 바꾸므로 실제 바퀴 절대각도와 반드시 맞아야 합니다.
