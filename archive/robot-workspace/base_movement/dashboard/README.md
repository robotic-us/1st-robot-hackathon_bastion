# SOLSHADE dashboard

외부 패키지 없이 동작하는 시연용 대시보드입니다.

로봇 실행:

```bash
cd /home/phorce/bastion_ws/base_movement
python3 dashboard/server.py --domain-id 21
```

브라우저에서 `http://localhost:8080`을 엽니다. 로봇을 움직이지 않고 UI만 시험하려면
`--dry-run`을 추가합니다.

기본 실행은 라이브 모드이며 버튼 동작마다
`phorce play <slot> --target robot --domain-id 21`을 시간 제한 없이 호출합니다. SD카드가 분리된 경우에도
시작각 안전 검사는 이 디렉토리의 동일한 로컬 모션 사본으로 수행합니다.

안전 검사는 로봇 피드백을 사용하지 않습니다. 서버 시작 시 모든 모터의 상대 위치를
0도로 초기화하고, 성공한 모션 CSV의 종료각을 다음 모션 CSV의 시작각과 비교합니다.
차이가 3도보다 크면 실행을 차단합니다. 높이 피니언(0x03/MD1)은 모션 전체 구간에서
상대 원점 0도 아래로 내려가는 명령을 항상 차단합니다.

주차 왕복 후 우산을 기본 상태로 복귀시킬 때는 제어 소스가 물리적으로 안정화되도록
주행 복귀와 우산 복귀 사이, 그리고 기울기 복귀와 높이 복귀 사이에 각각 3초를 기다립니다.

차량 정면 방위는 192.7도이며 후면에서 봤을 때 0도는 12시, 서쪽을 향하는 시계방향이
양(+)입니다. 태양 벡터를 차량의 좌우 기울기 평면에 투영해 동쪽은 음(-), 서쪽은
양(+)으로 계산하고 가장 가까운 0/10/20/30/40도 슬롯을 선택합니다. 태양 방위각은
계산에만 사용하고 화면에는 표시하지 않습니다.

화면 하단의 수동 조작 패널은 현재 채워진 슬롯을 기능별 10열 행으로 표시합니다.
수동 버튼도 자동 기능과 동일하게 시작각 안전 검사를 거친 뒤 실제 `phorce play`를
호출합니다. 이전 모션 종료각과 새 모션 시작각이 3도보다 다르면 경고하고 실행하지
않습니다.
