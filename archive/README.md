# Event workstation archive

This directory preserves event-related work that was found outside Git before
the organizer workstation was scheduled to be reformatted.

- `robot-workspace/`: ROS, motion, dashboard, AprilTag, and solar-tracking work
- `pcm/`: relative-teaching bundle and the pre-slot-41 SD-card motion backup
- `scripts/`: Phorce diagnostics, patching, recovery, and validation utilities
- `documents/`: organizer document drafts and the additional notice deck
- `packages/`: the event SDK update bundle used on the workstation
- `misc/`: small standalone participant/robot helper sources

Generated ROS build/install/log trees, Python caches, compiled extensions,
desktop installers, remote-desktop recordings, and system/application state
were intentionally excluded. The original directory structure is otherwise
kept so the work can be reconstructed after reformatting.
